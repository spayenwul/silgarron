## 🎯 Видение Проекта

**Silgarron** — это текстовая RPG, где:
- LLM является **физическим движком**, а не декоративным рассказчиком
- Нет абстрактных HP/урона — только реалистичная физическая симуляция
- Игрок может делать ЧТО УГОДНО и КАК УГОДНО (открытый мир действий)
- AI делает решения о последствиях, код применяет эти решения

---

## 📊 Текущий Статус Проекта

### Реализовано ✅
- **Базовая архитектура** (FastAPI backend + frontend)
- **IntentService** - маршрутизация команд (all-mini + pymorphy3)
- **Detail Extraction** - парсинг сложных команд
- **Event Sourcing** - журналирование событий
- **Hex Grid System** - тактические карты
- **BodySystem Skeleton** - скелет системы ран (awaiting physics team)
- **Configuration System** - централизованная конфигурация

### В Процессе 🟡
- **Director Refactoring** - интеграция нового архитектурного видения
- **World Generation** - процедурная генерация локаций
- **Physical Simulation Stubs** - заглушки для команды физики

### Не Начато 🔴
- **Function Calling Pattern** - паттерн вызова инструментов
- **Command Routing по сложности** - CODE_ONLY/SIMPLE_LLM/COMPLEX_TOOL_CALL
- **Physics Integration** - интеграция реальной физики (зависит от другой команды)

## 🏗️ Новая Архитектура: Три Уровня

### Уровень 1: Fast Router (IntentService)
**Технология:** all-mini + pymorphy3 + intents.json  
**Время:** <50ms  
**Задача:** Классификация команды по типу сложности

```
"бью мечом"     → SIMPLE_LLM
"посмотреть"    → CODE_ONLY
"опрокинуть стол на врага" → COMPLEX_TOOL_CALL
```

**Статус:** ✅ Реализовано (87% accuracy)

---

### Уровень 2: Director (Оркестратор)
**Задача:** Выбрать стратегию обработки на основе intent_type

```python
class Director:
    def route_command(intent_type, command):
        if intent_type == "CODE_ONLY":
            return self.execute_code_only()  # Мгновенно
        elif intent_type == "SIMPLE_LLM":
            return self.execute_simple_narrative()  # 1 API call
        elif intent_type == "COMPLEX_TOOL_CALL":
            return self.execute_function_calling()  # 2+ API calls
```

**Статус:** 🟡 Требует рефакторинга (текущий director устарел)

---

### Уровень 3: Стратегии Обработки

#### 🟢 Стратегия: CODE_ONLY
**Для:** Простые, детерминированные действия  
**Примеры:** посмотреть инвентарь, взять предмет, статистика персонажа  
**Обработка:** Python-код без AI  
**Стоимость:** 0₽  
**Время:** <10ms

#### 🟡 Стратегия: SIMPLE_LLM
**Для:** Простые действия с нарративом  
**Примеры:** ударить мечом (простая атака), осмотреться, поговорить  
**Обработка:** 1 вызов Gemini с контекстом  
**Стоимость:** ~0.001₽  
**Время:** 500-1000ms

#### 🔴 Стратегия: COMPLEX_TOOL_CALL (Function Calling)
**Для:** Сложные действия с физикой  
**Примеры:** опрокинуть стол, сложная комбинация атак, взаимодействие с окружением  

**Процесс:**
1. **Вызов 1:** Gemini получает команду → возвращает JSON-запрос к функциям кода
2. **Код выполняет** физические расчёты (вес, силу, траекторию)
3. **Вызов 2:** Gemini получает результаты → генерирует нарратив

**Стоимость:** ~0.002₽  
**Время:** 1000-2000ms
