### Понимание концепции:

**Сильгаррон ≠ Планета**
Это живой организм с:
- **Скелетом** (Костяной хребет - позвоночник)
- **Кровеносной системой** (Лимфатические каналы)
- **Дыхательной системой** (Альвеолярные каверны - лёгкие)
- **Метаболизмом** (Температура = активность тканей)
- **Тканями** (Биомы = типы тканей: дерма, мышцы, кость, хитин)

## 🎯 Цели спринта

### Главный результат:
Функция `generate()` которая по `seed` создаёт воспроизводимый мир 256×256 с:
- Анатомической структурой (хребет + мягкие ткани)
- Лимфатической сетью (реки как кровь)
- Дыхательными кавернами (источники спор)
- Автоматическим назначением тканей

### Критерии успеха:
- ✅ Один seed → всегда один и тот же мир
- ✅ Хребет выглядит как "позвоночник" (вертикальная ось)
- ✅ Лимфотоки текут логично (от хребта к низинам)
- ✅ Споровые ореолы вокруг каверн
- ✅ Визуализация как "медицинское сканирование"

## 📋 План реализации (5 фаз)

### Phase 1: Core Anatomical Generator (14-16 часов)
**Задачи:** 1.1 - 1.5
**Цель:** Создать базовый генератор с 5 системами

1. **Task 1.1: Base WorldGenerator structure** (2h)
   - Детерминированный seed (hashlib)
   - Структура класса
   - **Валидация:** seed "test" всегда даёт одинаковый результат

2. **Task 1.2: Skeletal structure (Ridge-biased Perlin)** (3-4h)
   - Perlin noise для микрорельефа
   - Ridge mask для "позвоночника"
   - Rib mask для "рёбер"
   - **Валидация:** Хребет проходит вертикально по центру

3. **Task 1.3: Lymphatic system (D8 Flow Accumulation)** (4-5h)
   - Поиск истоков (возвышенности)
   - D8 Flow Accumulation для русел
   - **Валидация:** Лимфотоки текут вниз от хребта

4. **Task 1.4: Respiratory system (BFS Exhalation)** (5-6h)
   - Poisson Disk Sampling для каверн
   - BFS для концентрации выброса
   - **Валидация:** Ореолы вокруг каверн

5. **Task 1.5: Metabolic activity** (2-3h)
   - Температура = f(elevation, lymph, exhalation)
   - **Валидация:** Хребет холодный, лимфа тёплая

### Phase 2: Tissue Assignment (6-7 часов)
**Задачи:** 2.1 - 2.2
**Цель:** Автоматическое назначение тканей

6. **Task 2.1: tissue_rules.yaml** (3h)
   - 9 типов тканей
   - Условия назначения
   - **Валидация:** Правила не конфликтуют

7. **Task 2.2: Tissue selection logic** (3-4h)
   - Система приоритетов
   - Проверка диапазонов
   - **Валидация:** Нет "голых" секторов

### Phase 3: Data Models (2 часа)
**Задача:** 3.1
**Цель:** Структуры данных

8. **Task 3.1: GlobalSector + GlobalMapData** (2h)
   - HexCoord (Axial + Cube)
   - GlobalSector (с анатомическими полями)
   - **Валидация:** Сериализация/десериализация

### Phase 4: Visualization (4 часа)
**Задача:** 4.1
**Цель:** "Медицинское сканирование"

9. **Task 4.1: 5-layer visualizer** (4h)
   - 5 слоёв + composite
   - Анатомическая палитра
   - **Валидация:** PNG без ошибок

### Phase 5: Configuration & Testing (12-15 часов)
**Задачи:** 5.1 - 5.3

10. **Task 5.1: world_generation.yaml** (1h)

## 🧪 Стратегия валидации

### Уровень 1: Unit Tests
Каждая функция тестируется изолированно:
- `test_perlin_noise_deterministic()` - один seed → один шум
- `test_ridge_mask_vertical()` - хребет вертикален
- `test_flow_accumulation_downhill()` - вода течёт вниз

### Уровень 2: Integration Tests
Системы работают вместе:
- `test_skeletal_system_creates_ridge()` - хребет виден
- `test_lymph_follows_elevation()` - лимфа в низинах
- `test_caverns_evenly_distributed()` - каверны равномерны

### Уровень 3: Visual Validation
Человеческая проверка:
- PNG визуализация после каждой фазы
- "Выглядит ли это как живой организм?"

### Уровень 4: Biological Plausibility
Правила биологии:
- Хребет холоднее равнин ✓
- Лимфа тёплая ✓
- Споры вокруг каверн ✓
