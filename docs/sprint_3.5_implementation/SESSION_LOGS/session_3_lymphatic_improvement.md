## Проблема, выявленная анализом

### Что было не так:

**Проблема:** Истоки размещались по всей карте случайным образом.

**Последствия:**
1. ❌ Нарушение анатомической метафоры
   - Вместо единой системы "кровообращения" от центра к периферии
   - Множество мелких, локальных, несвязанных систем

2. ❌ Нелогичные потоки
   - "Река" может начаться в низине
   - Через пару гексов впасть в другую низину
   - Неестественно для крупномасштабной системы

3. ❌ Несоответствие лору
   - Лор предполагает: истоки = "фильтрующие органы" в предгорьях
   - Лимфа течёт от хребта к низинам (очистные зоны)

### Техническая причина:

```python
# БЫЛО:
candidates = (
    (ridge_mask > min_ridge) &
    (elevation > min_elevation) &  # ❌ Только МИНИМУМ, без максимума!
    (flow_accumulation <= max_accumulation)
)
```

Параметр `min_elevation=0.6` означал: **"от 0.6 до 1.0"** (включая высокие пики).

Но нужно было: **"от 0.5 до 0.8"** (только предгорья).

---

## Реализованное решение

### Изменение 1: Параметр `elevation_range`

**Было:**
```python
def find_lymph_sources(
    elevation: np.ndarray,
    ridge_mask: np.ndarray,
    flow_accumulation: np.ndarray,
    num_sources: int = 8,
    min_elevation: float = 0.6,  # ❌ Только минимум
    ...
)
```

**Стало:**
```python
def find_lymph_sources(
    elevation: np.ndarray,
    ridge_mask: np.ndarray,
    flow_accumulation: np.ndarray,
    num_sources: int = 8,
    elevation_range: Tuple[float, float] = (0.5, 0.8),  # ✅ Диапазон!
    ...
)
```

### Изменение 2: Логика фильтрации

**Было:**
```python
candidates = (
    (ridge_mask > min_ridge) &
    (elevation > min_elevation) &  # ❌ Неограничено сверху
    (flow_accumulation <= max_accumulation)
)
```

**Стало:**
```python
min_elev, max_elev = elevation_range

candidates = (
    (ridge_mask > min_ridge) &
    (elevation >= min_elev) &      # ✅ Не слишком низко
    (elevation <= max_elev) &      # ✅ Не слишком высоко (предгорья!)
    (flow_accumulation <= max_accumulation)
)
```

### Изменение 3: Обновлённая документация

Добавлено в docstring:

```
Критерии отбора (анатомическая модель):
- Находятся на хребте (ridge_mask > min_ridge)
- В ПРЕДГОРЬЯХ (elevation в диапазоне [0.5, 0.8])
  → НЕ на самых высоких пиках (это "кость")
  → НЕ в низинах (это устья, а не истоки)
- Малая аккумуляция (локальные пики, не в руслах)

Биологическая интерпретация:
- Предгорья хребта = "фильтрующие органы" (почки, печень)
- Оттуда лимфа течёт вниз к периферии (очистные зоны)
- Единая интегрированная система от центра к краям
```

## Биологическая интерпретация

| Высота | Анатомия | Лимфатическая роль |
|--------|----------|-------------------|
| 0.8-1.0 | Костяной хребет (кость) | Нет истоков (твёрдая ткань) |
| **0.5-0.8** | **Предгорья (мягкие ткани)** | **ИСТОКИ лимфы (фильтрующие органы)** |
| 0.3-0.5 | Равнины (дерма, мышцы) | Основные русла (циркуляция) |
| 0.0-0.3 | Низины (впадины) | Устья (очистные зоны) |

**Теперь система работает как реальная лимфатическая система:**
1. Лимфа вырабатывается в "органах" (предгорья хребта)
2. Течёт через "ткани" (равнины)
3. Очищается в "лимфоузлах" (низины на периферии)

## Вопрос о "белых звёздах"

> "Что означает белая звезда на панелях 1 и 4?"

**Ответ:**
- **Красные звёзды** = истоки лимфотоков (8 источников)
- **Cyan звёзды (на панели 4)** = те же истоки, другой цвет для контраста

Это **фильтрующие органы** в лоре Сильгаррона:
- Расположены в предгорьях Склеритового хребта
- Вырабатывают лимфу (биолюм, питательные вещества)
- От них лимфа течёт по каналам к периферии

**Идея для лора:** Можно назвать эти точки "Лимфогенераторы" или "Фильтрующие узлы Хребта".
