## Ключевые решения

### 1. Почему собственная реализация Perlin Noise?
Вместо использования готовой библиотеки (например, `noise`):
- ✅ Полный контроль над алгоритмом
- ✅ Детерминированность гарантирована
- ✅ Векторизация через NumPy (~100x быстрее)
- ✅ Образовательная ценность (полное понимание)

### 2. Параметры Ridge и Ribs
**Ridge:** `exp(-5 * dist^2)`
- k=5 → узкий хребет (~20% ширины)
- k=2 → широкий хребет (~40% ширины)
- Выбрано k=5 для чёткого "позвоночника"

**Ribs:** Угол 30°, период 32 пикселя
- 30° → естественный наклон "рёбер"
- 32px → 8 "рёбер" на карту 256×256
- Strength 0.3 → не доминируют над хребтом

### 3. Веса комбинации
30% Base + 50% Ridge + 20% Ribs
- Ridge доминирует (50%) → "позвоночник" визуально главный
- Base (30%) → органическая текстура
- Ribs (20%) → детали, не перекрывают структуру
