## Проблема после первого улучшения

**Наблюдение пользователя:**
> "Результат на графиках почти не поменялся - слишком много хаотично разрозненных потоков"

**Анализ:**
Критерии были правильными по направлению, но **недостаточно строгими**:
- 8 истоков → слишком много локальных систем
- Диапазон [0.5, 0.8] → всё ещё широкий
- min_ridge=0.5 → принимаются слабые участки хребта
- top 10% каналов → показываются мелкие притоки

**Результат:** Множество мелких потоков вместо нескольких крупных артерий.

### Изменение 1: Меньше истоков

```python

# СТАЛО:
num_sources=6  # Меньше истоков = меньше хаоса
```

### Изменение 2: СТРОГО узкий диапазон высоты

```python

# СТАЛО:
elevation_range=(0.55, 0.75)  # УЗКИЙ диапазон (20%)
```

### Изменение 3: Только СИЛЬНЫЙ хребет

```python
# БЫЛО:
min_ridge=0.5  # Половина силы хребта

# СТАЛО:
min_ridge=0.7  # Только сильные участки (70%+)
```

### Изменение 4: Ещё строже с аккумуляцией

```python
# БЫЛО:
max_accumulation=5.0

# СТАЛО:
max_accumulation=3.0  # Ещё строже (только локальные пики)
```

### Изменение 5: Только главные артерии

```python
# БЫЛО:
threshold_percentile=90.0  # Top 10% аккумуляции

# СТАЛО:
threshold_percentile=95.0  # Top 5% (только ГЛАВНЫЕ русла)
```

### Изменение 6: Минимальное расстояние между истоками

**Новая функциональность:**
```python
min_distance = 40  # Минимум 40 пикселей между источниками

# Выбираем источники так, чтобы они были распределены по карте
for candidate in sorted_candidates:
    if all(distance(candidate, selected) >= min_distance for selected in selected_sources):
        selected_sources.append(candidate)
```

**Эффект:** Истоки равномерно распределены по хребту, не кучкуются в одном месте.

## Технические детали

### Алгоритм выбора истоков с min_distance:

```python
selected_sources = []
min_distance = 40  # пикселей

for candidate in sorted_by_height(candidates):
    # Проверяем расстояние до всех уже выбранных
    too_close = any(
        euclidean_distance(candidate, selected) < min_distance
        for selected in selected_sources
    )

    if not too_close:
        selected_sources.append(candidate)

    if len(selected_sources) >= num_sources:
        break
```

**Преимущества:**
- Истоки равномерно распределены по длине хребта
- Нет кучкования в одном месте
- Каждый исток обслуживает свою "зону" организма

### Анатомическая модель (усиленная):

```

=======      ========                =========
0.8-1.0      Костяной пик            -
                  ▲

0.75-0.8     Верхнее предгорье       -
                  │
[0.55-0.75]  ФИЛЬТРУЮЩАЯ ЗОНА        ⭐⭐⭐ ИСТОКИ (6 штук)

                  │                    ║  ║  ║

                  │                    ║  ║  ║
```

### Что изменилось:

**Стало:** Несколько крупных "артерий" от центра к периферии

Это **ближе к реальной анатомии**:
- Крупных лимфатических протоков немного (6-8)
- Они начинаются в "органах" (предгорья)
- Текут к периферии, собирая лимфу по пути
