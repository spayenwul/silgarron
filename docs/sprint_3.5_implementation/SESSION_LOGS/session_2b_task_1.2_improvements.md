## Проблемы, выявленные анализом

### Проблема 1: Ridge Mask слишком идеальный ❌
**Что было:**
- Идеально прямая вертикальная линия
- Идеально симметричный гауссов градиент
- Нет изгибов (wiggle), упомянутых в плане

**Оценка:** Для анатомического "позвоночника" слишком геометрично.

### Проблема 2: Rib Mask слишком регулярный ❌
**Что было:**
- Идеально прямые диагональные линии
- Одинаковое расстояние между всеми рёбрами
- Нет естественной кривизны

**Оценка:** Второй слой искусственности.

### Проблема 3: Неправильные веса смешивания ❌
**Что было:** 30% Base + 50% Ridge + 20% Ribs
**Что должно быть (по плану):** 60% Base + 30% Ridge + 10% Ribs

**Эффект:** Хребет "задавливал" естественность базового шума.

### Проблема 4: Отсутствие шума в масках ❌
**Что было:** Математически гладкие маски
**Что нужно:** Низкочастотный Perlin шум для органичности краёв

## Реализованные исправления

### Исправление 1: Ridge Mask с изгибами ✅

**Добавлено:**
```python
# Синусоидальные изгибы (wiggle)
wiggle_amplitude = 12  # пикселей
wiggle_frequency = 0.03  # ~8 волн на карту

# Основная синусоида + вторая гармоника
wiggle = wiggle_amplitude * np.sin(Y * wiggle_frequency * 2 * np.pi)
wiggle += wiggle_amplitude * 0.3 * np.sin(Y * wiggle_frequency * 2 * np.pi * 2.5 + np.pi/4)

# Центр хребта с изгибом
spine_center = center_x + wiggle
```

**Результат:**
- Хребет больше не прямой, а имеет змеевидную форму
- Две гармоники создают более сложный паттерн
- Амплитуда 12 пикселей → видимый, но не чрезмерный изгиб

**Добавлено:**
```python
# Низкочастотный шум для органичности краёв
ridge_noise = perlin.fractal_noise_2d(scale=4.0, octaves=2)
ridge = ridge * (0.9 + 0.2 * ridge_noise)
```

**Результат:**
- Края хребта больше не идеально гладкие
- 10% вариации интенсивности (±10% от базовой)

### Исправление 2: Rib Mask с изгибами и нерегулярностью ✅

**Добавлено:**
```python
# 1. Вариация угла наклона (±10 градусов)
angle_noise = perlin.fractal_noise_2d(scale=3.0, octaves=2)
angle_variation = angle_noise * 10
effective_angle = rib_angle + angle_variation

# 2. Вариация расстояния между рёбрами (±20%)
spacing_noise = perlin.fractal_noise_2d(scale=5.0, octaves=2)
rib_phase += spacing_noise * 0.2

# 3. "Толщина" рёбер (не линии, а объёмные структуры)
rib_wave = np.power(rib_wave, 1.5)

# 4. Общая органичность
organic_noise = perlin.fractal_noise_2d(scale=6.0, octaves=2)
ribs = ribs * (0.8 + 0.4 * organic_noise)
```

**Результат:**
- Рёбра больше не параллельны (угол варьируется)
- Расстояние между рёбрами нерегулярно
- Рёбра имеют "толщину", а не тонкие линии
- Общая модуляция шумом (±20% интенсивности)

**Параметры изменены:**
- `rib_spacing`: 32 → 40 (меньше рёбер, больше промежутки)
- `rib_strength`: 0.3 → 0.15 (вдвое слабее)

### Исправление 3: Корректные веса смешивания ✅

**Было:**
```python
elevation = base_elevation * 0.3 + ridge_mask * 0.5 + rib_mask * 0.2
```

**Стало:**
```python
elevation = base_elevation * 0.6 + ridge_mask * 0.3 + rib_mask * 0.1
```

**Эффект:**
- Базовый шум теперь доминирует (60%) → естественность
- Хребет структурирует (30%) → анатомия
- Рёбра добавляют детали (10%) → тонкие акценты

### Исправление 4: Визуализация изгиба хребта ✅

**Добавлено в `visualize_skeletal.py`:**
