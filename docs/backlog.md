## 🚀 SPRINT 2: Function Calling Implementation

**Статус:** Запланировано  
**Зависимости:** Sprint 1 завершён  
**Приоритет:** 🔴 Критический

### Цель
Реализовать полноценный паттерн вызова инструментов (Function Calling) для сложных команд.

### Задачи

#### 2.1 Спроектировать Tool Registry
- [ ] Создать `services/tool_registry.py`
- [ ] Определить схему регистрации функций
- [ ] Документировать каждый инструмент для LLM

**Пример:**
```python
class ToolRegistry:
    def __init__(self):
        self.tools = {
            "calculate_physics": {
                "description": "Calculate physical results of an action",
                "parameters": {
                    "action": "push/pull/throw",
                    "object_mass_kg": "float",
                    "force_newtons": "float"
                }
            }
        }
```

#### 2.2 Реализовать Tool Functions
- [ ] `tools/physics_tools.py` - физические расчёты (заглушки)
- [ ] `tools/inventory_tools.py` - работа с инвентарём
- [ ] `tools/world_tools.py` - информация о мире
- [ ] Написать тесты для каждого инструмента

#### 2.3 Интеграция с Gemini API
- [ ] Обновить `llm_service.py` для function calling mode
- [ ] Обработка ответов с `tool_calls`
- [ ] Итеративный вызов (запрос → tool → ответ)

#### 2.4 Обновить FunctionCallingStrategy
- [ ] Заменить заглушку реальной реализацией
- [ ] Логирование всех tool calls для отладки

#### 2.5 Тестирование
- [ ] E2E тест: "опрокинуть стол на врага"
- [ ] Проверить корректность JSON-запросов
- [ ] Валидация результатов tool calls

**Время:** ~20 часов  
**Результат:** LLM может вызывать Python-функции и получать реальные данные
