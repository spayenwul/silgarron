## 🎯 Единая концепция генерации

### Фундаментальное решение противоречия

**Проблема:**
Противоречие "Органы первичны" vs "Континент первичен" создавало концептуальный конфликт в документации и реализации.

**Решение:**
Гибридная модель **"Анатомический Каркас → Географическое Воплощение → Детальная Физиология"**

### Новая последовательность генерации

```
PHASE 1a: Анатомический Каркас (Spine Creation)
    ↓
    Генерация позвоночного хребта - первичной анатомической структуры
    Опциональное размещение 1-2 структурообразующих органов

PHASE 1b: Географическое Воплощение (Continent Growth)
    ↓
    Континент "вырастает" вокруг хребта через Spine Influence Mask
    Суша напрямую зависит от формы анатомии

PHASE 2: Детальная Анатомия (Organ Placement)
    ↓
    Размещение остальных органов на уже существующем континенте
    Органы размещаются в осмысленном географическом контексте

PHASE 3-8: Физиология, Геология, Климат, Ткани...
    ↓
    Все последующие слои строятся на прочном фундаменте
```

### Преимущества новой модели

✅ **Решает Цель №1 (Вариативность):**
Форма хребта уникальна для каждого seed → уникальная география

✅ **Решает Цель №2 (Узнаваемый костяк):**
Мир всегда имеет центральный хребет как анатомическую ось

✅ **Решает Цель №3 (Географическая разница):**
Уникальная форма хребта → уникальная форма континента (заливы, проливы)

✅ **Решает Цель №4 (Правила создания суши):**
Суша создаётся вокруг анатомии, реализуя принцип "Органы первичны"

## 🗺️ Изменения размеров карты

### Старый размер (ADR-012, устарел)

**Этап 0 (Глобальные Скелеты):** 256×256
**Этап 1 (Детализация):** 4096×4096

**Проблема:**
256×256 было недостаточно для создания детализированных, органичных континентов с плавными береговыми линиями.

### Новый размер (ADR-021)

**Этап 0 (Глобальные Скелеты):** **512×512**
**Этап 1 (Детализация Чанков):** **4096×4096**
**Масштабный коэффициент:** 1 hex Этапа 0 = 8×8 hexes Этапа 1

**Обоснование:**
- ✅ Более детализированные континенты
- ✅ Лучшее размещение органов и регионов
- ✅ Плавная береговая линия
- ✅ Больше места для spine path (100 точек вместо 50)
- ⚠️ Незначительное увеличение времени генерации (~0.20 сек вместо ~0.10 сек)

### Таблица замены

| Контекст | Было | Стало | Обоснование |
|----------|------|-------|-------------|
| Размер карты Этапа 0 | 256×256 | **512×512** | Больше деталей |
| Center координата | (128, 128) | **(256, 256)** | Центр карты |
| Spine path points | 50-80 | **100** | Плавнее изгибы |
| Max influence radius | 100-150 | **200-250** | Шире континент |
| Organ radius (typical) | 15-30 | **Без изменений** | Относительный размер сохраняется |

## 📐 Spine-Based Generation - основной метод

### Старая парадигма (устарела)

**Подходы:**
1. Pure Perlin Noise (без маски) - случайный континент
2. Ellipse/Radial Mask - центрирование геометрическими фигурами

**Проблемы:**
- ❌ Pure Perlin: континент может выходить за границы, нет океана
- ❌ Ellipse: центрирование есть, но **нет анатомического смысла**
- ❌ Оба подхода не реализуют принцип "анатомия → география"

### Новая парадигма (основная)

**Spine-Based Generation** - это **единственный канонический метод** для основной генерации.

**Философия:**
> "Континент — это тело, выросшее на скелете, а не геометрическая фигура."

**Последовательность:**
1. **Spine Creation:** Процедурно генерируется изогнутый позвоночник (север → юг)
2. **Influence Field:** Создаётся поле влияния вокруг хребта (distance transform)
3. **Continent Growth:** Perlin Noise × Spine Influence → континент растёт вокруг хребта

**Результат:**
- ✅ Анатомический каркас определяет географию
- ✅ Уникальная форма для каждого seed (изгиб хребта)
- ✅ Полная реализация концепции "От анатомии к географии"

### Статус других методов

**Ellipse/Radial Mask:**
- **Статус:** ❌ **Устаревший/Legacy**
- **Документация:** Заархивирована (`archive/SHAPE_MASK_GUIDE.md`)
- **Использование:** Только для специфических тестов или экспериментов
- **Не рекомендуется** для основной генерации миров

**Pure Perlin (без маски):**
- **Статус:** ⚠️ **Экспериментальный**
- **Использование:** Только для технических тестов алгоритма Perlin Noise
- **Не подходит** для финальной генерации (нет гарантии океана по краям)

## 🆕 v3.0 Architecture Changes (October 2025)

**Дата:** 29 октября 2025
**Версия:** 3.0 (расширение v2.0)
**Статус:** 🚧 В планировании

### Критические изменения порядка фаз

**Проблема v2.0:**
Артерии (Phase 2) генерировались ДО скелета (Phase 3), что логически неверно - подземные артерии должны огибать массивные костные структуры, а не бурить их насквозь.

**Решение v3.0:**
Phase 2 (Vessels) ↔ Phase 3 (Skeleton) **поменялись местами**.

### Новая последовательность фаз (v3.0)

```
Phase 0: Seed & Meta ✅
Phase 1a: Spine Creation ✅
Phase 1b: Continent Growth ✅
Phase 2: SKELETON (кости, рёбра, elevation) 🚧 → НОВЫЙ ПОРЯДОК
Phase 3: VESSELS (артерии с density-aware pathfinding) 🚧 → НОВЫЙ ПОРЯДОК
Phase 4: Base Hydrology (D8 flow + vein outlets) 🚧
Phase 4.5: HYDRAULIC EROSION (фокусированная эрозия) 🆕 → НОВАЯ ФАЗА
Phase 5: Climate (temperature, moisture) 🚧
Phase 6: Respiration (skeleton-driven caverns) 🚧
Phase 7: Tissues (с Worley noise вариантами) 🚧
```

### Ключевые улучшения v3.0

#### 1. Phase 2: Skeleton First

**Что изменилось:**
- Phase 2 теперь генерирует скелет, elevation, И **bone_density_map**
- Bone density map используется в Phase 3 для pathfinding артерий
- L-Systems для генерации рёбер (более органичная форма)

#### 2. Phase 3: Density-Aware Vessels

**Что изменилось:**
- Артерии генерируются с использованием **Space Colonization Algorithm**
- Алгоритм учитывает плотность костей (`bone_density_penalty = 3.0`)
- Артерии **огибают** кости, используя путь наименьшего сопротивления
- Результат: реалистичная сеть сосудов, избегающая скелета

**Ключевые параметры:**
```python
bone_density_penalty = 3.0  # Штраф за прохождение через кости
influence_radius = 50.0     # Дальность "притяжения" к органам
kill_distance = 10.0        # Расстояние "достижения" цели
segment_length = 5.0        # Детализация пути
```

#### 3. Phase 4.5: Hydraulic Erosion (NEW)

**Новая фаза** между Phase 4 (Hydrology) и Phase 5 (Climate).

**Что создаётся:**
- Реалистичное "вымывание" ландшафта водными потоками
- "Лимфатическая эрозия" - лимфа выходит на поверхность в точках артерий

**v3.0 Улучшения:**
1. **Предварительная обработка:** Gaussian smoothing (sigma=2.0) убирает резкие артефакты от L-Systems
2. **Фокусировка источников:** Мощные источники в vein_outlets (×100), слабый фоновый дождь (0.01)
3. **Bone protection:** Кости эродируются в 3 раза медленнее (30% скорости)

**Результат:**
- Глубокие V-образные долины вдоль рек
- Плавные переходы высот
- Кости сохраняют форму
- Реки "прорезают" ландшафт, создавая каньоны

#### 4. Phase 7: Worley Noise Варианты (NEW)

**Что добавлено:**
- Вариативность метрик (Euclidean vs Manhattan) для разнообразия зон
- Комбинирование шумов (Worley × Perlin) для сложных паттернов
- Использование Worley noise как **генератора данных** для свойств гексов

### Философия v3.0

> **"От анатомии к географии, от логики к реализму"**

v3.0 усиливает концепцию v2.0, делая генерацию более **логически последовательной** и **физически правдоподобной**:
- Скелет создаётся раньше артерий (логика)
- Артерии огибают кости (физика)
- Эрозия создаёт реалистичные долины (реализм)
- Worley noise создаёт разнообразие (эмерджентность)
