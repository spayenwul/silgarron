# Тюнинг параметров генерации континента

## Проблема

После реализации Phase 2 было обнаружено, что генерация может давать:
- Слишком высокочастотный шум (много мелких островов)
- Неоптимальный баланс суша/океан
- Недостаточно плавные континенты

## Решение: Grid Search оптимизация

### Инструмент для тюнинга

**Создан:** `scripts/tune_continent_parameters.py`

**Функции:**
```bash
# Тюнинг одного параметра
python scripts/tune_continent_parameters.py --param scale
python scripts/tune_continent_parameters.py --param sea_level
python scripts/tune_continent_parameters.py --param octaves

# Полный grid search
python scripts/tune_continent_parameters.py --full-grid
```

## Влияние параметров

### 1. scale (Частота Perlin Noise)

**Низкий scale (50-100):**
- Высокочастотный шум
- Много мелких деталей
- Хаотичная береговая линия
- ❌ Не подходит для континентов

**Оптимальный scale (150-200):**
- Низкочастотный шум
- Плавные, крупные формы
- Органичная береговая линия
- ✅ **Идеально для континентов**

**Высокий scale (250-300):**
- Очень плавные формы
- Может быть слишком однородно
- Теряются детали
- ⚠️ Слишком упрощенно

### 2. sea_level (Порог океана)

**Низкий sea_level (0.25-0.30):**
- 90-99% суши
- Почти нет океана
- ❌ Несбалансировано

**Оптимальный sea_level (0.35-0.40):**
- 60-80% суши
- 20-40% океана
- ✅ **Хороший баланс**

**Высокий sea_level (0.45-0.50):**
- 0-20% суши
- Много мелких островов
- ❌ Больше архипелаг, чем континент

### 3. octaves (Слои детализации)

**octaves=1:**
- Очень гладкие формы
- Нет мелких деталей
- Простые континенты
- ⚠️ Может быть слишком просто

**octaves=2:**
- Плавные формы с умеренными деталями
- Естественная береговая линия
- ✅ **Оптимально для континентов**

**octaves=3-4:**
- Много мелких деталей
- Холмистый рельеф
- ✅ Хорошо для **детализации** (Sprint 3.9)

## Морфологические операции

### Текущие параметры (оптимальные):

```yaml
smoothing:
  binary_opening_iterations: 3   # Удаляет мелкие острова
  binary_closing_iterations: 2   # Заполняет мелкие заливы
  gaussian_sigma: 3.0             # Финальное сглаживание
  final_threshold: 0.5            # Порог после blur
```

**Эффект:**
- Убирает одиночные пиксели в океане
- Соединяет близкие участки суши
- Создает плавные береговые линии
- Уменьшает количество островов с сотен до 1-2

### Если нужно больше сглаживания:

```yaml
gaussian_sigma: 5.0  # Было 3.0 - более плавные контуры
```

### Если нужно больше деталей:

```yaml
binary_opening_iterations: 2   # Было 3 - сохраняет больше островов
gaussian_sigma: 2.0             # Было 3.0 - менее агрессивное сглаживание
```

## Как менять параметры

### Вариант 1: Через конфиг-менеджер

```python
from services.world_config_v2 import WorldGenerationConfigV2

config = WorldGenerationConfigV2.from_yaml('config/world_generation_v2.yaml')

# Изменяем параметры
config.set_sea_level(0.40)
config.set_perlin_scale(180)
config.set_perlin_octaves(3)

# Сохраняем
config.save_to_yaml('config/world_generation_v2.yaml')
```

### Вариант 2: Прямое редактирование YAML

Откройте `config/world_generation_v2.yaml`:

```yaml
continent:
  perlin_noise:
    scale: 150      # Измените здесь
    octaves: 2

  sea_level: 0.38   # Измените здесь

  smoothing:
    gaussian_sigma: 3.0  # Измените здесь
```
