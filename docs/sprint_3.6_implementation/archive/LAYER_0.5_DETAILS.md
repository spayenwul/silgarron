### Новая философия СЛОЯ 0.5: Композитное формирование континента

**Проблема:** Простой низкочастотный Perlin Noise создаст *случайный* континент. Он не гарантирует наличия "Хватательной конечности" или "Острова-глаза".

**Решение:** Мы используем **композитный подход**. Вместо одной карты шума мы создадим несколько "масок" для каждой ключевой анатомической части и затем объединим их в единое целое.

Это позволяет сочетать процедурную генерацию (для органичных, уникальных деталей) с авторским контролем (для узнаваемой формы).

### Скорректированный алгоритм для СЛОЯ 0.5

Вот как теперь будет выглядеть генерация континента:

#### Шаг 1: Генерация базовой маски (Центральный континент)

Это основа, "туловище" Сильгаррона.
*   **Метод:** Используем низкочастотный Perlin Noise, как и планировалось, но с одним дополнением: мы можем добавить **вертикальный эллиптический градиент**, чтобы придать континенту более вытянутую форму вдоль оси "позвоночника".
*   **Результат:** `base_continent_mask` — основной, вытянутый массив суши.

#### Шаг 2: Генерация маски "Хватательной конечности"

Это самая сложная и интересная часть.
*   **Метод:**
    1.  Найти подходящую "точку крепления" на юго-восточном или юго-западном "побережье" `base_continent_mask`.
    2.  Сгенерировать **процедурный путь** (например, с помощью смещенного случайного блуждания или кривой Безье), идущий от точки крепления в сторону от континента. Это будет "рука".
    3.  В конце пути сгенерировать более крупную, "кулакообразную" область (можно использовать еще один, более мелкий Perlin Noise или просто несколько смещенных кругов).
    4.  Объединить путь и "кулак" в единую маску `limb_mask`.
*   **Результат:** Отдельная маска, представляющая собой длинный полуостров с утолщением на конце.

#### Шаг 3: Генерация маски "Острова-глаза"

*   **Метод:**
    1.  Найти подходящую точку в "океане" (где `base_continent_mask == false`), на некотором расстоянии от основной суши, предпочтительно в "верхней" части карты (у "головы").
    2.  Сгенерировать в этой точке небольшую маску острова, например, эллиптической формы.
*   **Результат:** `eye_island_mask`.

#### Шаг 4: Композиция и сглаживание

*   **Метод:**
    1.  Объединить все маски в одну с помощью логической операции `OR`:
        ```
        final_mask = base_continent_mask | limb_mask | eye_island_mask
        ```
    2.  Применить к `final_mask` **процедуры сглаживания**, которые уже есть в вашем плане (`binary_opening`, `binary_closing`, `gaussian_filter`). Это "срастит" конечность с континентом и придаст всем береговым линиям естественный вид.
*   **Результат:** Финальная `continent_mask`, которая имеет узнаваемую, но при этом уникальную для каждого `seed` форму.

### 🟡 СЛОЙ 0.5: ФОРМИРОВАНИЕ КОНТИНЕНТА (macro-relief)

**Первичность:** 0.5 - определяет "холст" для организма

**Философия:**
> Сильгаррон — это не случайный континент. Его форма следует **узнаваемым анатомическим правилам**. Генератор должен процедурно создавать эту форму, обеспечивая уникальность деталей при сохранении общей структуры: **Центральный континент, Хватательная конечность и Остров-глаз**.

**Что создаётся:**

#### 0.5.1. Композитное формирование маски суши

**Метод:** Создание и объединение нескольких процедурных масок.

```python
# --- Шаг 1: Центральный континент ("Туловище") ---
# Низкочастотный шум для основной формы
base_continent_noise = generate_perlin_noise(
    seed=hash(world_seed + "continent_base"),
    scale=150, octaves=2
)
# Эллиптический градиент для придания вытянутой формы
y, x = np.ogrid[:height, :width]
ellipse_gradient = 1.0 - np.sqrt(((x - width/2)**2 / (width*0.4)**2) + ((y - height/2)**2 / (height*0.5)**2))
ellipse_gradient = np.clip(ellipse_gradient, 0, 1)

# Комбинируем шум и градиент, чтобы получить вытянутый, но органичный континент
base_continent_mask = (base_continent_noise * 0.5 + ellipse_gradient * 0.5) > 0.45

# --- Шаг 2: Хватательная конечность ("Рука с кулаком") ---
# Находим точку "крепления" на южном побережье
attachment_point = find_coast_point(base_continent_mask, direction='south-east')
# Генерируем путь от этой точки
limb_path_mask = generate_procedural_path(
    start=attachment_point, 
    direction=(-45, -20), # Диагонально вниз
    length=150, 
    width=20, 
    randomness=0.3
)
# На конце пути генерируем "кулак"
fist_center = get_path_end(limb_path_mask)
fist_mask = generate_perlin_blob(
    center=fist_center, 
    radius=40, 
    seed=hash(world_seed + "limb_fist")
)
limb_mask = limb_path_mask | fist_mask

# --- Шаг 3: Остров-глаз ---
# Находим точку в океане, к северо-востоку от центра континента
eye_island_center = find_offshore_point(
    base_continent_mask, 
    direction='north-east', 
    distance=(80, 120)
)
eye_island_mask = generate_ellipse_mask(center=eye_island_center, size=(25, 15))

# --- Шаг 4: Композиция и сглаживание ---
# Объединяем все части
final_mask = base_continent_mask | limb_mask | eye_island_mask

# Сглаживаем береговую линию для естественного вида
final_mask = morphology.binary_opening(final_mask, iterations=3)
final_mask = morphology.binary_closing(final_mask, iterations=2)
continent_mask = gaussian_filter(final_mask.astype(float), sigma=3) > 0.5
```

**Результат:** Целостная маска суши с узнаваемым силуэтом, но с уникальными, процедурно сгенерированными деталями для каждого `seed`.

#### 0.5.2. "Укладка" анатомии на континент

**Метод:** (Без изменений) Все последующие слои (органы, кости) генерируются **только в пределах `continent_mask`**, используя её центр масс и главную ось как ориентиры.
