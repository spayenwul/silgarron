# Sprint 3.6 - Phase 2: Генерация континента (РЕЗУЛЬТАТЫ)

## Что было реализовано

### 1. Генерация континента с Perlin Noise

**Файл:** `core/world_generator_v2.py` - метод `_generate_continent()`

**Алгоритм (ADR-016 compliant):**

```
1. Perlin Noise (scale=150, octaves=2) → базовый heightmap
2. Threshold (sea_level=0.35) → continent_mask
3. Морфологические операции → сглаживание береговой линии
   - Binary opening (3 iterations) - удаляет маленькие острова
   - Binary closing (2 iterations) - заполняет маленькие заливы
4. Gaussian blur (sigma=3.0) → финальное сглаживание
5. PCA → расчет центра масс и главной оси
```

**Ключевое отличие от Phase 1:**
- **До (Phase 1):** Идеальный круг с радиальным градиентом
- **После (Phase 2):** Органичная форма с уникальной береговой линией для каждого seed

### 2. Геометрический анализ континента

**Реализованные методы:**

- `_calculate_center_of_mass()` - центр масс континента (scipy.ndimage)
- `_calculate_major_axis()` - главная ось через PCA (numpy.linalg.eig)

**Назначение:**
- Центр масс используется для размещения центральных органов (metabolic_organ)
- Главная ось определяет "позвоночник" мира для размещения neural_clusters

## Визуальное сравнение: До vs После

### До (Phase 1 - Геометрический круг)
```
Континент:
- Идеальный круг радиусом 150px
- Центр: (256, 256) - всегда в центре карты
- Ось: (106, 256) → (406, 256) - всегда горизонтальная
- Форма: Полностью предсказуемая
- Уникальность: 0% (каждый seed идентичен)
```

### После (Phase 2 - Perlin Noise)
```
Континент:
- Органичная форма с заливами и полуостровами
- Центр: Динамический, зависит от формы континента
- Ось: Динамическая, вычисляется через PCA
- Форма: Уникальная для каждого seed
- Уникальность: 100% (каждый seed уникален)
```

## Параметры для тюнинга

### Текущие параметры (config/world_generation_v2.yaml)

```yaml
continent:
  perlin_noise:
    scale: 150      # Масштаб "волн" (50-300)
    octaves: 2      # Количество слоёв детализации (1-5)
    persistence: 0.6  # Затухание амплитуды (0.0-1.0)
    lacunarity: 2.0   # Рост частоты (1.5-4.0)

  sea_level: 0.35   # Порог океана (0.2-0.5)

  smoothing:
    binary_opening_iterations: 3
    binary_closing_iterations: 2
    gaussian_sigma: 3.0
    final_threshold: 0.5
```

### Рекомендации по тюнингу

**Больше океана:**
```yaml
sea_level: 0.40  # Было 0.35
```

**Более крупные континенты:**
```yaml
perlin_noise:
  scale: 200  # Было 150
```

**Больше деталей (острова, архипелаги):**
```yaml
perlin_noise:
  octaves: 3  # Было 2
```

**Более гладкая береговая линия:**
```yaml
smoothing:
  gaussian_sigma: 5.0  # Было 3.0
```
