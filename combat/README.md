Физическая боевая система с реалистичной симуляцией.

- `wounds.py` - Система ран
- `status_effects.py` - Физические статус-эффекты
- `body_system.py` - Анатомическая система
- `context_builder.py` - Сборка физического контекста (Phase 3)
- `physical_simulator.py` - AI-симуляция физики (Phase 3)
- `effect_applicator.py` - Применение эффектов (Phase 3)
