## 🎯 Приоритеты реализации

### ВЫСОКИЙ ПРИОРИТЕТ (Фаза 3.1)

1. **`wounds.py` - Механика ранений**
   - [ ] Реалистичный расчет кровотечения в зависимости от местоположения раны
   - [ ] Скорость артериального и венозного кровотечения
   - [ ] Расчет повреждения тканей (кожа, мышцы, кости, органы)
   - [ ] Естественное свертывание крови с течением времени
   - [ ] Оценка тяжести ранения

2. **`status_effects.py` - Система эффектов**
   - [ ] Логика взаимодействия эффектов (шок от потери крови)
   - [ ] Уменьшение эффективности при суммировании эффектов
   - [ ] Развитие конкретных эффектов (боль утихает, кровотечение усиливается)
   - [ ] Модификаторы для игровых механик (боль снижает точность)

3. **`body_system.py` - Основная физиология**
   - [ ] Схемы строения тел для разных видов (загрузка из файлов данных)
   - [ ] Расчет сознания (кровяное давление, травма головы)
   - [ ] Механика шока (потеря крови + травма)
   - [ ] Проверки на мгновенную смерть (жизненно важные органы, обезглавливание)

### СРЕДНИЙ ПРИОРИТЕТ (Фаза 3.2)

4. **Продвинутые типы ранений**
   - [ ] Ушибы (внутреннее кровотечение, повреждение органов)
   - [ ] Ожоги (разрушение тканей, риск инфекции)
   - [ ] Урон от яда/токсина (системные эффекты)
   - [ ] Обморожение (некроз тканей)

5. **Зоны попадания по частям тела**
   - [ ] Точные хитбоксы для прицеливания
   - [ ] Места для критических попаданий (глаза, горло, сердце)
   - [ ] Покрытие броней по зонам
   - [ ] Ограничение подвижности (конечности)

6. **Сериализация**
   - [ ] Полное сохранение/загрузка всех данных о ранениях
   - [ ] Сохранение/загрузка статусных эффектов с полным состоянием
   - [ ] Обратная совместимость со старыми сохранениями

### НИЗКИЙ ПРИОРИТЕТ (Фаза 3.3+)

7. **Механика лечения**
   - [ ] Медицинская помощь (перевязка, хирургия)
   - [ ] Естественное заживление со временем
   - [ ] Шрамы и постоянные травмы
   - [ ] Лечебные предметы (зелья, магия)

8. **Продвинутая физиология**
   - [ ] Системы органов (сердце, легкие, печень)
   - [ ] Симуляция метаболизма (голод, жажда)
   - [ ] Терморегуляция
   - [ ] Болезни и инфекции
